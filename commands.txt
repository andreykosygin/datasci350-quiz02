---
title: "Budget and Revenue"
---

This page explores the relationship between film production budgets and box office revenue. 

```{python}
#| echo: true
#| label: fig-budget-revenue
#| fig-cap: "Relationship between film production budget and box office revenue"

import pandas as pd
import matplotlib.pyplot as plt

films = pd.read_csv("films.csv")

plt.figure(figsize=(7, 5))
plt.scatter(films["budget"], films["revenue"], alpha=0.5)
plt.xlabel("Budget")
plt.ylabel("Revenue")
plt.title("Budget vs. Revenue")
plt.show()
```
EOF

---
title: "Runtime and Ratings"
---

This page examines the relationship between film runtime and IMDb ratings. 

```{python}
#| echo: true
#| label: fig-runtime-rating
#| fig-cap: "Relationship between film runtime and IMDb rating"

import pandas as pd
import matplotlib.pyplot as plt

films = pd.read_csv("films.csv")

plt.figure(figsize=(7, 5))
plt.scatter(films["runtime"], films["imdb_rating"], alpha=0.5)
plt.xlabel("Runtime (minutes)")
plt.ylabel("IMDb Rating")
plt.title("Runtime vs. IMDb Rating")
plt.show()
```

## Average IMDb Rating by Decade

The following table reports the mean IMDb rating for films released in each decade.

```{python}
#| echo: true

films["decade"] = films["year"] // 10 * 10
films.groupby("decade")["imdb_rating"].mean().round(2)
```

cat << 'EOF' > bond.qmd
---
title: "The Bond Films"
---

This page explores how James Bond film revenues have changed over time.

```{python}
#| echo: true

import pandas as pd
import matplotlib.pyplot as plt

films = pd.read_csv("films.csv")

bond = films[films["franchise"] == "James Bond"]
bond = bond.sort_values("year")
```

The James Bond films in this dataset span from `{python} int(bond["year"].min())` to `{python} int(bond["year"].max())`.

```{python}
#| echo: true
#| label: fig-bond-revenue
#| fig-cap: "James Bond film revenue over time"

plt.figure(figsize=(7, 5))
plt.plot(bond["year"], bond["revenue"], marker="o")
plt.xlabel("Release Year")
plt.ylabel("Revenue")
plt.title("James Bond Revenue Over Time")
plt.show()
```
EOF
